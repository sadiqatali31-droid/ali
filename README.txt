INSANIYAT HELP WEBSITE
Created by Amjad Ali ChinjnI

HOW TO OPEN:
1. Download and extract the ZIP file.
2. Open the extracted folder.
3. Double-click index.html to open the website in Chrome or another browser.

FILES:
- index.html : Website page and registration form
- style.css  : Colors, layout and mobile-friendly design
- script.js  : Simple form interaction

IMPORTANT:
This is a front-end demo project. The registration form does NOT send, store, or forward information to an organization. To collect real registrations, connect it to a secure backend and arrange a trusted person/organization to review requests. Do not publish people's private information or promise assistance you cannot provide.
